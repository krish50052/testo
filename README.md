# Testo - Mock Test Interface

An interactive, responsive online mock examination platform replicating real test environments (Guidely/TCS iON style).

## Features
- **Multi-screen Exam Flow**: Instructions, Language Selection, Exam Environment, Section/Final Summary Modals, and Final Scorecard.
- **Comprehensive Scorecard & Result Analysis**:
  - Net Score calculation (+2.00 for correct, -0.50 for wrong, 0 for unattempted).
  - Negative marking penalty impact spotlight showing gross score, penalty deductions, and score lost ratio.
  - Section-wise breakdown table with detailed accuracy and marks.
- **Interactive Question Paper & Answer Key Review**:
  - Filter questions by Negative Marked only, Correct answers, or Unattempted.
  - Color-coded question options (highlighting correct answers in green and user mistakes in red).
  - Detailed step-by-step solutions and explanations in English and Hindi.
  - 100-question quick jump palette.
- **Section Management**: Real-time switching between sections (General Intelligence & Reasoning, General Awareness, Quantitative Aptitude, English Comprehension).
- **Interactive Question Palette**: Tracks question states (Answered, Not Answered, Not Visited, Marked for Review, Answered & Marked).
- **Timer & Auto-pause**: Countdown timer with pause/resume functionality.
- **Multi-language Support**: English and Hindi language toggles.
- **Responsive Design**: Desktop and mobile layouts with full-screen and print/PDF support.
- **Automated Test Suite**: Built-in 18-assertion test dashboard (`test_runner.html`).

## Getting Started
- Open `index.html` in any modern web browser to start the mock examination.
- Open `test_runner.html` to run the automated test suite and view the assertion dashboard.
